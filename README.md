# Fun Math Scripts

This project is a collection of math-related scripts and demos written in JavaScript

### Installation

There is no installation needed besides Node.js!

### How To Use

Each file can be run simply by using the node command, i.e. `node fibonacci.js`

### Types of Demos

This project includes demos/code for the following:
1. Collatz Conjecture Simulator (read more about it [here](https://en.wikipedia.org/wiki/Collatz_conjecture))
1. Fibonacci Sequence Generator
1. Prime Number Checker
1. Square Root Calculator (using Newton's method)
